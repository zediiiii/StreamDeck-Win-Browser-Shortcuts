# Changelog

## v1.0
First public version.

- Focus any open Edge tab from a Stream Deck key, via UI Automation
- Works across multiple Edge windows and profiles
- Durable match strings derived from tab title structure, not a curated list
- Double-press opens the tab when it is closed; single press launches Edge
- Reads real tab URLs from the omnibox so buttons can reopen closed tabs
- Generates launchers, favicon key images, and importable `.streamDeckAction`
  files
- Live match validation, toast notifications on failure, rotating log
